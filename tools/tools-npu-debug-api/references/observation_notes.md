# 观测结果与限制

资料基线及版本适用性见 [平台与编程模式支持矩阵](platform_matrix.md#来源基线)。

## 精度观测

`asc_dump` 可提供指定地址空间的中间数据，`printf` 可补充标量、索引和分支条件。有效对照要求输入、阶段、核/线程、数据索引及参考值相匹配，且被观测数据满足原有同步和生命周期要求。

某阶段输入与参考值一致、输出偏离时，该阶段是偏差候选位置；输入已经偏离时，输出偏差不足以证明该阶段存在缺陷。没有中间参考值时，打印仅提供局部证据。增加打印或同步后症状消失也不能证明问题已修复。

## 常见异常的影响因素

| 现象 | 相关限制与影响因素 |
| --- | --- |
| 完全没有输出 | 平台/模式支持、头文件与命名空间、执行路径、线程过滤、`ASCENDC_DUMP=0` |
| 输出不全 | SIMD/SIMT FIFO 容量、SIMD VF 预留 UB、单条记录大小、每核输出量 |
| 多核输出顺序异常 | 多核文本输出没有可依赖的全局顺序；阶段标签、`desc` 和核/线程标识用于区分来源 |
| 断言未触发 | 条件为真、路径未执行、`NDEBUG`、`ASCENDC_DUMP=0` 或模式不支持 |
| 断言或 Trap 中断 | 断言通常提供源码位置和条件；`__trap` 本身不提供完整上下文，也不负责恢复 |
| 转储数据异常 | 地址空间、模板类型、实际有效长度、起始地址、32 字节补齐及特殊 Buffer 的结果格式 |
| 周期数据异常 | 起止点的线程和逻辑阶段、异步操作、冷启动、编译优化及打印开销 |
| 时间戳缺失 | `ASCENDC_TIME_STAMP_ON`、NPU 实机要求、入图限制及每核累计量 |

各项仅适用于涉及该接口的场景，详细调用形式及限制见对应接口参考。
