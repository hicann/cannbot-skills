# AICPU 性能实验

本 Skill 提供实验设计与证据判读，不预设性能测试工具、阈值或带宽目标。先确认目标版本源码、真实可用的测试程序和计时定义；没有可用测量环境时输出 `UNVERIFIED` 与缺项。运行命令和外部资源授权由调用方提供。

## 固定可比较的实验

1. 写明优化目标：算子、拓扑/rank、通信域、dtype、数据量范围、指标及其单位、被比较的算法和允许改变的默认选路范围。指标计算以目标测试程序的实际计时和字节定义为准。
2. 为基线与候选记录源码/包哈希、CANN/HCOMM、测试程序、集群、链路、环境变量、并发负载、预热和重复次数。改变其中一项时分组报告，不能直接归因为算法收益。
3. 确认实际选中了目标算法。显式 `HCCL_ALGO` 是定向实验，默认选择是另一实验；DSL、注册全名、成本候选及通信域配置优先级按 [选路契约](../hccl-aicpu-best-practice/references/executor-selector.md) 核对。未标定成本系数不能当作性能估计。
4. 候选先取得适用的完整构建及 [A/B 双轨功能证据](../hccl-aicpu-best-practice/references/build-verification.md)。[HCCL-VM](../hccl-test-tool-hvm/SKILL.md) 的 Checker 用于功能正确性，不能证明延迟或带宽提升。
5. 在同条件下保存每次原始测量、预热/失败/异常样本、统计口径和计算过程；报告基线与候选分布及差异。若观测值受环境波动影响，给出重复实验或单变量定位建议，不筛掉不利样本制造收益。

输出为实验范围、工具与版本、可比较性、原始证据、算法命中、功能验证身份、统计结果、可能的瓶颈假设与未验证项。没有真实测量时只给实验方案；任何性能结论都不能替代默认选路授权、功能回归或上层任务完成判定。
