# CANNBotDSL 代码检视

## 输入

- 调用方指定的算子源码文件、目录或 PR 差异。
- 可选：算子规格、设计资料、Unit 和测试结果，用于理解代码职责与排除误报。

## 输出

在调用方指定的位置写可读性检视报告。每项发现包含文件、准确行号、最短必要代码片段、问题、分级、证据与修复建议；没有发现时也给出明确结论。报告格式参考 [报告写法](steps/report-write.md)。

## 检视方法

1. 实际阅读目标代码和必要的调用上下文，按 [可读性规则](references/readability-rules.md) 检查命名、魔数与结构风格。规则来自真实 DSL 算子检视语料，只提供判断线索。
2. 按 [检视方法](core/methodology.md) 对候选问题检测、核实、判定。每条正反证据都引用真实代码行；缺少证据的候选不判为 FAIL。
3. 报告使用 FAIL、SUSPICIOUS、待确认分级。语料外发现单独标注，不强行套入现有规则；需要作者判断时写清待确认事项。

本 Skill 提供检视方法与报告内容。调用方安排执行角色、并行和报告路径。
