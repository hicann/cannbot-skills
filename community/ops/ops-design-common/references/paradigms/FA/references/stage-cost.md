# FA 阶段成本与排布选择

用于 S4、S5、S6 联合比较基本块、交错排布与任务分配。按所选 FA 计算图展开阶段；本表对应 C1→V1→C2→V2 的在线 softmax 路径。量化、稀疏或新增阶段在相应输入范围重新计数，设备耗时注明依据。

## 1. 逐阶段计数

定义有效输出行数 m、当前 KV 行数 n、分数收缩维度 d、值输出维度 d_v。task g 的有效 KV 工作项数为 L_g，总数 `N=sum_g L_g`。固定初始化、每工作项计算与最终归一化分别计数。

| 阶段 | 资源及调用次数 | 每工作项计算 | 数据与重复操作 | 依赖及状态 |
|---|---|---|---|---|
| Q 装载 | 所选搬运通路，每 task 的实际次数 | 按实际重排计数 | 逻辑 `m*d` 元素；按共享范围与物理布局记录装载及转换 | 保留到最后 C1 读取完成 |
| C1 | Cube，按有效 KV 项及 d 子块数 | QK 约 `2*m*n*d` FLOPs | K 装载、Q/K 到计算存储、S 搬出；按子块与布局统计重复次数 | S 发布给对应 V1 |
| V1 | Vector，每有效 KV 项 | scale/mask、max、exp、sum 与在线 m/l 更新 | S 读取、P 转换与交接；分别计入各存储层级 | m/l 按 task 更新，alpha 按工作项保留 |
| C2 | Cube，按有效 KV 项及输出子块数 | PV 约 `2*m*n*d_v` FLOPs | V 装载、P/V 读取及 B 搬出；输出分段时统计 P 再读取次数 | B 发布给对应 V2 |
| V2 | Vector，每有效 KV 项 | U 缩放、累加约与 `m*d_v` 成正比 | B、alpha 与 U 的真实读写 | U 更新按所属 task 顺序 |
| 最终输出 | Vector/输出通路，每 task 一次 | U/l、转换及约定的统计输出 | 输出写回，状态与结果的最后读取 | 完成后释放所属 task 的状态 |

上述计算量是有效量；实际对齐、完整访问宽度、尾部及填充产生的执行量另外计入。S/P/B 的写与读分别记账，P 的转换两侧和片上搬运与外部存储流量分别记录。分段、共享或重置引起的重复操作按实际内外循环展开。

## 2. 共用资源的吞吐约束

Cube 内 C1/C2 的计算负载合计；Vector 内 V1/V2 的负载合计。搬运引擎、片上路径和存储带宽按实际共用关系合并。目标平台的 Cube/Vector 配比与可参与执行的核数采用已确认事实，逐行分摊与物理容量使用同一口径。

```text
tau >= max(
    C1 与 C2 在同一 Cube 实例上的累计占用,
    V1 与 V2 在同一 Vector 实例上的累计占用,
    共享搬运通路和存储带宽的占用,
    在线状态及有限缓冲带来的推进约束
)
```

每个时间分量明确计算、搬运、转换或等待；已确认独立且可重叠的分量按最大值形成下界，串行分量沿依赖链累计。峰值与有效吞吐分别注明来源，实际可达到的推进间隔由所选时序支持。

## 3. 候选排布比较

[完整示例](pipeline-example.md) 选择 V1 先于 V2，保存每工作项 alpha，并把 task 的 m/l 与 U 分开保留。V2 先于 V1 的候选按其读写顺序重新求未释放版本数。新增份数、释放时点和等待变化进入资源及成本比较。

| 候选及完整输入 | C1/V1/C2/V2 的次数与偏移 | 各层搬运及重复次数 | m/l、alpha、U 与交接份数 | 共用资源与关键等待 | 选择依据及后续观测 |
|---|---|---|---|---|---|
| 实际方案 | 逐 task 与 KV 项代入 | Q/K/V、S/P/B、状态与输出 | 分别求生命周期与物理分配 | 推进间隔限制 | 估算、已测或待测 |

改变预取、块大小、状态保留或阶段顺序时，重新代入计算、搬运、份数、填充及排空。容量中包含所有副本、布局填充、临时区与同步存储；当前方案中的数值仅支持其前提及路径。

## 4. 短流、task 边界与最慢核

- 少量 KV 项：按完整时间表计算初始填充与剩余 V1/C2/V2，工作项数不足时按实际发射次数计算。
- 多个相邻 task 连续推进：计算跨 task 同时保留的 m/l、alpha、Q 与输出状态；初始化和最后读取分别定位到具体阶段。
- 每 task 排空或分段重置：按实际边界次数累计开销，并核对输入、workspace 及状态可见性。
- 多核分配：按各 task 的有效 m/n、KV 项数、内部子块数估算各核负载，总计算阶段取最慢核，再计最终汇合与输出。

长流可用 `T_setup + T_first_item + (N-1)*tau + T_finish` 作近似结构；T_first_item 包含首项经过完整阶段链的延迟，T_finish 只计最后阶段后剩余收尾。变长 task、短流与不同阶段成本按具体排布推导。

## 5. 输出与验证义务

设计中给逐阶段成本、候选资源代入、预计瓶颈与选择范围。后续实现验证按相同语义、合法输入与统计条件比较：

- KV 工作项较少与较多，区分填充/排空和长流推进间隔。
- m/n/d/d_v 改变，检查 C1/C2、V1/V2 与搬运成本的相对变化。
- 相同输出范围、不同 task 划分，检查重复装载、各核负载和收尾次数。
- V1/V2 顺序或缓冲候选改变，检查代次安全、复用等待与实际重叠。

总时延结合阶段或资源时间线、搬运/转换次数及等待证据判断归因；观察不符时修订遗漏的调用、状态依赖或分配成本。数值结果仍由独立 attention 参考计算判定。
