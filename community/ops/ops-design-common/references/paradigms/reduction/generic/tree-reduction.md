# Reduction 范式二分缓存树（树形归约累加模型）

> **层级**：通用知识层（generic/），语言中立。
>
> 来源：adapters/ascendc/binary-tree.md（原 reduction-binary-sum.md）全文。片上归约指令（`REDUCE_OP` 谓词）的调用细节在适配层。

## 1 背景与问题

对 N 个数归约，片上单次只能载入 B 个数，必须分块处理：将 N 个数分成 M=⌈N/B⌉ 块，逐块载入片上、用向量指令归约成 1 个部分结果，最后把 M 个部分结果合并成最终结果。

**核心问题：如何合并这 M 个部分结果，使浮点累加误差尽可能小？**

## 2 为什么用二分树

**顺序累加的精度问题**：维护一个累加器逐块累加，随着累加器增大，后续部分结果相对量级越来越小。浮点加法中两个量级差异大的数相加会丢失有效位，**误差随累加次数线性增长，为 O(M)**。

**树形归约的优势**：把 M 个部分结果两两配对、逐层合并，树高仅 log₂(M)。每一层相加的两个数量级相近，有效位损失小，**误差增长为 O(log M)**。

## 3 非 2 幂的处理：主尾配对

二分树要求叶子数为 2 的幂，但 M 一般不是 2 的幂。

取 P = **严格小于** M 的最大 2 幂，尾段 T = M − P。将尾段 T 块与主段前 T 块**两两配对合并**，每对产生 1 个部分结果：

```
Phase A (配对, i=0..T-1):
    chunk[i] 与 chunk[i+P] 配对
    → 载入两块 → 逐元素运算合并成 1 块 → 归约 → 1 个部分结果

Phase B (独立, i=T..P-1):
    chunk[i] 单独处理
    → 载入 → 归约 → 1 个部分结果
```

配对后，树的输入数恰好为 P（2 幂），形成完美二叉树。

> **为什么取"严格小于"而非"≤"**：当 M 本身为 2 幂时（如 M=16），取 P=M/2=8 而非 M=16，树深少 1 层，缓存空间省一个槽；代价是需多做 M/2 次配对。用一点计算换空间更划算。

> 配对时两块**逐元素**运算合并成一个块再归约，而非各自归约后再合并两个标量——元素级配对精度更好，且只调一次归约指令。尾块可能不足 B 个数，与主块配对时将尾块的有效元素逐元素作用到主块对应位置即可（等价于尾块按 identity 补齐再逐元素合并），不影响归约结果。

## 4 顺序循环中的树形归约

### 4.1 核心挑战

单核顺序执行，无法真正并行做树形归约。传统树形归约需保存全部叶子，当 P 较大时片上空间不够。需要一个机制：**在顺序循环中，把每个部分结果写到正确的树层级，用 L=log₂(P)+1 个缓存槽轮转复用，替代保存全部叶子的空间开销**。

### 4.2 多级缓存

在片上开辟 L 个缓存槽，L = log₂(P) + 1：

| 层级 | 含义 | 覆盖范围 | 写入频率 |
|------|------|---------|---------|
| cache[0] | 1 个部分结果 | 1 块 | 每 1 次迭代 |
| cache[1] | 2 个部分结果的合并 | 2 块 | 每 2 次迭代 |
| cache[2] | 4 个部分结果的合并 | 4 块 | 每 4 次迭代 |
| … | … | … | … |
| cache[L-1] | 全部 P 个部分结果的合并 | P 块 | 最后 1 次（树根） |

### 4.3 写入层级规则

迭代序号 i 的二进制表示中，**末尾连续 1 的个数**决定写入层级：

```
level(i) = i 的二进制末尾连续 1 的个数
```

直觉：与二进制计数器的进位传播一致——当低位全为 1 时，加 1 会触发连续进位，进位传播到第几位，就对应写入第几层。

| i | 二进制 | 末尾 1 个数 | 写入层级 | 动作 |
|---|--------|-----------|---------|------|
| 0 | 0000 | 0 | cache[0] | 直接写入 |
| 1 | 0001 | 1 | cache[1] | 吸收 cache[0]，写入 |
| 2 | 0010 | 0 | cache[0] | 直接写入 |
| 3 | 0011 | 2 | cache[2] | 吸收 cache[0,1]，写入 |
| … | … | … | … | … |
| 2^k−1 | …111 | k | cache[k] | 吸收 cache[0..k-1]，写入（该层树根）|

### 4.4 写入时的吸收规则

写入 cache[k] 前，先把 cache[0], cache[1], ..., cache[k-1] 全部吸收（合并），再覆盖写 cache[k]：

```
写入 cache[k]:
    result = 当前部分结果
    for j = 0 to k-1:
        result = result + cache[j]    // 正序吸收所有低层
    cache[k] = result                  // 覆盖写本层
```

**为什么必须正序（j=0→k-1）吸收**：cache[j] 覆盖 2^j 块的数据量，正序吸收保证每步相加的两个数量级匹配（1 块 + 1 块 → 2 块量级 → + 2 块 → 4 块量级 → …），精度最优。倒序吸收会让量级悬殊的数相加，破坏二分树的精度优势。**顺序不能变**。

**为什么是覆盖写而非累加写**：cache[k] 此前保存的是上一轮同层写入的旧值（已被更高层吸收过）。若累加，会把过期旧值叠进当前结果，导致重复计算。

### 4.5 树填充过程（P=16）

```
i=0:  cache[0]=S                                  树: [S, _, _, _, _]
i=1:  cache[1]=S+cache[0]                         树: [_, S, _, _, _]
i=2:  cache[0]=S                                  树: [S, _, _, _, _]
i=3:  cache[2]=S+cache[0]+cache[1]                树: [_, _, S, _, _]
...
i=15: cache[4]=S+cache[0]+cache[1]+cache[2]+cache[3]  树: [_, _, _, _, S] ← 根
```

迭代结束后，cache[L-1]（最高层）即全部输入的归约结果。

## 5 主流程伪码（语言中立）

```
输入: N 个数, 片上单块容量 B
M = ceil(N / B)               # 总块数
P = FindNearestPower2(M)      # 主段长度（严格小于 M 的最大 2 幂）
T = M - P                     # 尾段长度
L = log2(P) + 1               # 缓存树层数

for i = 0 to P-1:
    # 1. 载入并归约
    if i < T:                            # Phase A: 主尾配对
        load chunk[i]    → buf0
        load chunk[i+P]  → buf1
        buf0 = elementwise_merge(buf0, buf1)
        result = reduce(buf0)
    else:                                # Phase B: 独立
        load chunk[i]    → reduce → result

    # 2. 写入缓存树
    k = GetCacheID(i)                    # 末尾连续 1 的个数 = 写入层级
    DoCaching(k, result)                 # 正序吸收所有低层，覆盖写 cache[k]

answer = cache[L-1]                      # 树根 = 最终结果
```

辅助函数：

```
FindNearestPower2(value):    # 严格小于 value 的最大 2 的幂；value 为 0 或 1 时特例
    if value == 0: return 0
    if value <= 2: return 1
    return 1 << floor(log2(value - 1))

GetCacheID(idx):             # 二进制末尾连续 1 的个数 = 写入层级
    return count_ones(idx ^ (idx + 1)) - 1
```

## 6 设计要点总结

1. **主尾配对解决非 2 幂**：M 拆成 P（严格小于 M 的最大 2 幂）+ T，尾段与主段前 T 块配对，树输入数为 2 幂。M 为 2 幂时取 P=M/2，树深少 1
2. **末尾 1 规则编码树结构**：顺序循环中无需显式建树，迭代序号的二进制性质天然形成树形依赖
3. **正序吸收低层再覆盖写**：低层旧值已被吸收，覆盖不影响正确性，且不需要额外缓冲
4. **精度**：每层相加的两个数量级相近，误差 O(log P) 而非顺序累加的 O(M)
5. **空间极小**：缓存树仅需 L=log₂(P)+1 个结果槽，远小于保存全部中间结果

## 7 与片上归约指令的两级树关系

片上归约指令（`REDUCE_OP` 谓词）内部通常也用树形/折叠累加处理**单个 chunk 内**的归约；本范式二分缓存树处理**跨 chunk** 的累加。两者构成两级树：

- **指令级树**：chunk 内，指令内部的折叠（精度由 `REDUCE_OP_PRECISION` 谓词描述）
- **范式级树**（本文档）：chunk 间，cacheBuf 二分缓存树

范式无需关心指令内部实现——传入块形状，指令返回单次归约结果；范式树进一步保证跨 chunk 累加精度与确定性。
