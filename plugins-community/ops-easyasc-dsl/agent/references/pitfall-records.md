# Pitfall Index

Use this page to route recurring failures to their current owner document. It
does not retain dated debugging narratives, rejected hypotheses, or benchmark
timelines. Open work belongs in the affected owner README, while stable rules
belong in the focused references below.

| Failure signature | Stable rule | Owner and regression | Status |
|---|---|---|---|
| Mix-side generated C++ references an undefined dynamic GM helper view | Strict side provenance flows from dynamic helper views through scalar reads/writes, derived Vars, and their control flow. Static unscoped GM scalar access remains shared. | `agent/references/code-paths.md` -> "Parser-side dead-code or pruning behavior"; `agent/example/testcases/parser/core/test_gm_helper_side_propagation.py` | Resolved and regression-tested |
| A5 mix-side codegen emits a cube `PipeBarrier` such as `PIPE_M` on the vec side | Route `M` / `MTE1` / `FIX` barriers to cube only, `V` / `MTE3` to vec only, and `ALL` / `MTE2` / `S` to both sides. This ownership rule is separate from barrier synchronization semantics. | `doc/api/barrier.md` -> "Mixed-kernel side routing"; `easyasc/parser/asc.py` (`_instruction_side`); `agent/example/testcases/parser/core/test_side_pruning_codegen.py` | Resolved and regression-tested |
| A5 NZ/strided UB packing is correct in simulator but about 30% slower on board | Do not use a power-of-two fractal-row stride for scatter-style UB stores. Pad to an odd stride and exclude the pad on UB-to-L1 publication. | `agent/references/constraints/a5.md` -> "UB bank conflict on NZ / strided stores"; `agent/example/kernels/a5/attention/pfa/qk_softmax_pv_flat.py` | Resolved; board timing required for new layouts |
| A5 per-token scalar staging passes simulator but later rows misaddress on board when packed densely | A repeated one-element GM-to-UB or UB-to-GM burst needs one 32-byte physical UB row per token. Use `[L, dtype.C0]` backing and access `[row, 0]`; this does not forbid an isolated unaligned `.single()` address. | `agent/references/constraints/a5.md` -> "Per-token scalar bursts need one 32-byte row per token"; `agent/example/projects/a5/kda_bwd/README.md` | Resolved in the retained KDA kernels; board validation required for new layouts |
| CANN package build cannot find a generated ACLNN source/header although kernel math is valid | Match the public `@kernel` name to the CANN op type's snake-case filename, especially around acronym groups. | `agent/playbooks/cann-bench-aclnn-evaluation.md` -> "Pre-build deployment checklist" | Resolved as a mandatory pre-build check |
| First vec UB-to-L1 publish is later overwritten by a cube-side L1 zero-fill prologue | `auto_sync()` is same-side only. Add a one-time cube-MTE2 to vec-MTE3 edge after overlapping L1 initialization. | `agent/references/constraints/sync.md` -> "Cross-side L1 initialization needs an explicit prologue edge" | Resolved pattern; explicit event remains required |
| A2 diagonal causal masking fails on a narrow packed-mask row view | Apply the invalid suffix directly to aligned score rows before rowmax; packed masks do not waive local alignment rules. | `agent/references/patterns/online-softmax-tail.md` -> "Block-wise causal tail" | Resolved pattern |
| A2 `SelectMode.TENSOR_SCALAR` silently rewrites `NaN` lanes to the broadcast scalar fallback | Do not invert a finite-value predicate just to fit scalar-select operand order; A2 float compares are unordered-false for `NaN`, so `NaN` lanes take the scalar source. Keep `SelectMode.TENSOR_TENSOR` when the false side must carry per-lane values. | `agent/example/kernels/a2/vec_only/gelu_general.py` exact-mode erf select | Resolved in the merged GELU kernel |
| A2 `GetValueFrom` reads stale UB data after producing it with vector work when guarded by a single-pipe barrier | A scalar (PipeS) read of a UB value just produced by vector work needs `bar_all()` / `barrier(Pipe.ALL)` before `GetValueFrom`; `bar_v()` does not drain the cross-pipe visibility edge. | `agent/example/kernels/a2/vec_only/exp_general.py` (`prepare_base_factor`) | Resolved in the merged Exp kernel |
| A constant Python `if` appears to specialize a kernel/VF but both structures trace or a hardware branch is emitted | Normal `if/elif` in decorated code must resolve to a runtime `Var`/expression. The parser rejects plain bool/int conditions; dispatch structural variants to separate agent/example/kernels/VFs in Python. | `agent/references/authoring-preflight.md`; `agent/example/testcases/parser/core/test_constant_python_if_guard.py` | Rejected before code generation |
| Simulator passes but generated C++ fails because a loop counter shadows a Tensor/Reg/RegList/MaskReg | Give `range(..., name=...)` a name distinct from every live generated declaration and nested loop. Parser validation catches known collisions. | `agent/references/authoring-preflight.md`; `agent/example/testcases/parser/core/test_loop_identifier_collision.py` | Rejected before side split |
| A2 DataCopyPad silently does no work at `n_burst=4096` | A2 `gm_to_ub_pad` and `ub_to_gm_pad` accept only `[0,4095]`; split a larger transfer. Static and simulator-runtime guards both enforce the field width. | `agent/references/simulator-datamove-footprint-guards.md`; `agent/example/testcases/codegen/datamove/test_a2_datacopy_pad_n_burst.py` | Rejected before transfer |
| Matmul writes a partial into a nonzero L0C row offset and simulator passes while hardware leaves it uninitialized | Keep the matmul destination at L0C row offset zero. N/column sub-offsets have separate supported addressing. | `agent/references/constraints/tiling.md`; `agent/references/facts-simulator-opexec.md` | Requires layout correction and hardware validation |
| A synchronization test passes because each core processes only one outer tile | Force the same active core to reuse the slot across multiple outer tiles; for M-tiled attention require `ceil(BH * ceil(S1 / TILE_M) / core_count) > 1`. | `agent/references/authoring-preflight.md`; affected kernel regression | Mandatory reuse-shape regression |

Before adding a new entry, first decide whether it is an unresolved owner task
or a stable device/parser/simulator rule that belongs in an existing owner
reference. Add an incident here only when it needs a durable cross-route lookup
after that ownership is established.
