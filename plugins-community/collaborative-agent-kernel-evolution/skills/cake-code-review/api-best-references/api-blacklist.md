# API 黑名单

> **永远检查，无论算子使用了哪些 API。**
> 扩展方式：直接在本文件追加新行，无需修改其他文件。

## 禁止在生产代码中使用

| API | 禁止原因 | 替代方案 |
|-----|---------|---------|
| `GlobalTensor::SetValue()` | 逐元素操作，效率极低，严重影响性能 | `DataCopyPad` |
| `GlobalTensor::GetValue()` | 逐元素操作，效率极低，严重影响性能 | `DataCopyPad` |
| `DataCopy(GM↔UB)` 直接调用 | 无法处理非对齐数据，运行时越界风险 | `DataCopyPad` |

## 仅允许调试时使用（禁止合入生产）

| API | 限制原因 | 正确用法 |
|-----|---------|---------|
| `AscendC::printf(...)` | 严重影响性能，禁止在正式 kernel 中使用 | 仅用于单点调试验证，调试完毕必须删除 |
