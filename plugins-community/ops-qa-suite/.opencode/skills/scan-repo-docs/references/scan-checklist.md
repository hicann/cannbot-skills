## 五、评分规则

### 评分公式

```
评分 = 100 - (严重问题数 × 15) - (中等问题数 × 5) - (轻微问题数 × 1)
```

### 评分等级

| 评分范围 | 评级 | 说明 |
|---------|------|------|
| 90-100 | 优秀 | 无严重问题，少量轻微问题 |
| 80-89 | 良好 | 无严重问题，少量中等问题 |
| 60-79 | 一般 | 有严重问题或较多中等问题 |
| 40-59 | 较差 | 多个严重问题 |
| 0-39 | 不合格 | 大量严重问题 |

## 六、特殊场景处理

### 场景1：仓库不涉及AI CPU

如果仓库明确不涉及AI CPU算子开发：
- AI CPU相关检查项应标记为"跳过"
- 不计入问题统计

### 场景2：无NPU环境

如果无NPU环境执行验证：
- 命令执行验证标记为"跳过"
- 仅检查命令语法正确性

### 场景3：experimental目录

experimental目录下的算子：
- 可能文档不完整，应标注"experimental"
- 降低严重程度评级
