# 本仓编码红线

本 skill 列出本仓算子编码中**明确禁止的红线**及每条红线**触发后的解决方案**。红线均为「违反 = 检视不通过」的硬约束，编码与检视时逐条核对；不含泛泛的主体编码规则，只收录明确的禁止项。

> 本文件只做路由。红线条款与解决方案在 `references/` 中按需加载，不在此内联。
> 本目录是基类**默认红线**（属 virtual），各算子仓可 override 为本仓专用红线；override 时保持 `name:` 与逻辑名 `repo-coding-rules` 不变。
