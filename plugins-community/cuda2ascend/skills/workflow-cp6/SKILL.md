# CP6 CI 通过确认验收标准

本验收点判定**上库前的交付闭环**，即 CI 是否最终通过、检视意见是否已闭环，作为算子交付的收口确认。

## 验收对象

CI 报告（编译 + UT + ST 结果）+ PR 状态（检视意见及其处理情况）。

## 通过指标

以**CI 结果状态 + 检视意见闭环状态**判定，不凭主观印象：

- **CI 全绿**：CI 流水线的编译、UT、ST 三段均为通过状态，无失败、无告警级阻塞项（codecheck 问题已清零）。
- **检视意见闭环**：PR 上的检视意见全部处于已解决 / 已确认状态，无未回应或未修复的遗留意见。
- **状态一致**：CI 报告对应的是 PR 当前最新提交，非过期结果。
- **通过条件**：CI 三段全通过 + 检视意见零遗留同时满足。判定形式为"对照 CI 状态位与意见闭环清单，客观状态裁定"。

## 验收步骤

加载本 skill 时执行：

1. 读取 CI 报告，核对编译 / UT / ST 三段状态位是否全绿、codecheck 是否清零。
2. 核对 CI 报告是否对应 PR 最新提交。
3. 遍历 PR 检视意见，核对是否全部闭环、无遗留。
4. 汇总裁定，给出上库确认结论。

## 输出

本验收点产出**上库确认**结论：

- **通过**：明确结论"CI 通过确认"，附 CI 各段状态与意见闭环记录，标记交付闭环。
- **不通过**：返回**结构化修改意见**——
  - 问题定位：逐条列出未通过的 CI 段（编译 / UT / ST 具体失败项）或未闭环的检视意见。
  - 问题语义归属：codecheck 问题 或 PR 检视意见（指明是哪类）。该回退循环受「过程有界」约束，超过最大轮次暂停并向用户报告当前问题清单。

只验收不执行；不修改代码、不代替修复、不重新触发 CI（触发由对应流程执行）。
