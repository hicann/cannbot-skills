# CP0 环境确认验收标准

本验收点判定**开发环境是否满足算子开发要求**。本验收点固定为**用户确认模式**——环境是否可用只有用户能拍板，不由 agent 自动裁定；子仓可覆写问卷检查项与呈现方式，但"由用户最终确认"不可覆盖。

## 验收对象

环境信息文档，记录 NPU 设备、CANN 环境、编译环境等各项检查结果（每项含检查对象、期望值、实测值、是否符合）。

## 通过指标

以**结构化问卷 + 用户确认**判定，不凭主观印象：

- 将文档中每一项校验结果整理为问卷条目，逐项呈现"期望值 / 实测值 / 是否符合"。
- **通过条件**：所有校验项均标记为"符合"，且用户在问卷中确认无异议。
- 存在任一"不符合"项，或用户提出异议，即为不通过。
- 具体检查项集合与达标基线由绑定实现给定，判定形式固定为"逐项对照 + 用户勾选确认"。

## 验收步骤

加载本 skill 时执行：

1. 读取环境信息文档，逐项抽取"检查对象 / 期望值 / 实测值 / 是否符合"。
2. 生成结构化问卷 json：每个校验项一条，列出上述四要素，附"确认 / 异议"选项。
3. 问卷 json 作为验收产物返回，交由上游发送给用户；用户结论回传后作为本验收点的最终结果。

## 输出

- **通过**：明确结论"环境确认通过"，附用户确认记录。
- **不通过**：返回**结构化修改意见**——
  - 问题定位：逐条列出不符合的检查项及期望值 / 实测值差异。
  - 问题语义归属：环境校验结果不达标。由用户决定是修复环境后重新校验，还是终止开发。

只呈现结果与整理问卷，不修改环境、不执行修复、不代替用户决策。
