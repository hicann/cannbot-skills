# `kb/` 本地资料约束

1. 官方 AscendC 知识、索引和检索规则归 `cannbot-knowledge` 所有；不要在 port 插件中
   新增其副本，也不要新增指向插件内旧知识布局的路径。
2. `shared/` 只存放 port 运行时必须直接加载的规则和协议，不作为知识查询语料。
3. `okf/reference/porter/` 只保留 port 自有且尚未外迁的资产。新增文件前应先确认它
   不属于外部知识仓的维护范围。
4. 插件运行时不得修改本目录；新经验写入用户知识层。
5. 删除或移动本地资料时，必须同步检查 brief、agent、skill、脚本和测试中的消费者，
   并以行为测试验证不存在失效引用。
