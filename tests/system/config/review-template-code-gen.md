### 可编译性（满分 30，阈值 15）
**评测方法**：在算子项目目录下执行编译命令，检查是否生成可执行文件。
**编译步骤**：
1. 进入算子项目目录：`cd operators/{operator_name}`
2. 执行编译脚本：`bash run.sh`（或 `bash run.sh --skip-build` 跳过编译直接运行）
3. 检查编译产物：`ls -la build/{operator_name}`

**评分标准**：
- 编译成功，生成可执行文件：30 分
- 编译成功，但有警告：25 分
- 编译失败，但 CMake 配置正确：15 分
- 编译失败，CMake 配置错误：0 分

**注意事项**：
- 编译环境需要正确的 CANN 安装和环境变量配置
- 如遇到编译错误，检查 CMakeLists.txt 配置、依赖库路径、NPU 架构设置

### 可运行性（满分 30，阈值 15）
**评测方法**：执行编译后的可执行文件，检查运行结果和精度验证。
**运行步骤**：
1. 进入算子项目目录：`cd operators/{operator_name}`
2. 执行运行脚本：`bash run.sh --skip-build`（跳过编译，直接运行）
3. 检查运行输出：查看是否生成 output.bin 文件
4. 检查精度验证：查看 verify_result.py 的输出结果

**评分标准**：
- 运行成功，精度验证通过：30 分
- 运行成功，精度验证失败：15 分
- 运行失败，但生成了部分输出：10 分
- 运行失败，无输出：0 分

**注意事项**：
- 运行需要 NPU 设备可用
- 如遇到运行错误，检查环境配置、设备状态、输入数据格式
- 精度验证标准：rtol=1e-3, atol=1e-3（FP16）
