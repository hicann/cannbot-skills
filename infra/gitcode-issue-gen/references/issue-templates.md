# Issue 模板格式

按 Issue 类型选择对应模板（创建 Issue 时根据 PR 变更性质自动选择，参见主文档「内容生成规范」决策）。

## Feature Request

```markdown
#### 一、背景信息
[新需求的功能是什么，解决了什么问题]

#### 二、价值/作用
[该需求的价值，应用场景等]

#### 三、设计方案
[设计的总体思路]

关联 PR：https://gitcode.com/{owner}/{repo}/pull/{pr_number}
```

## Bug Report

```markdown
#### 一、问题描述
[描述产生了什么问题]

#### 二、重现步骤
[如何重现该缺陷]

#### 三、预期结果
[描述预期的行为]

关联 PR：https://gitcode.com/{owner}/{repo}/pull/{pr_number}
```
