# Markdown 合规性质检规则 - 规范性检查详细说明

**重要提示：**

- 仅使用本文件中明确定义的规则进行检查
- 规则名称、规则级别必须与本文件完全一致

## 1. 规范性

检查文档中术语使用、表格格式和隐私信息的合规性。此类检查仅基于文档内容，不需要读取代码。

| 规则项名称 | 规则名称 | 规则类型 | 描述 | 级别 |
| --- | --- | --- | --- | --- |
| StaticCheck_compliance | 术语检查 | 规范性 | 检查文档中术语和缩略语的使用规范性 | 提示 |
| StaticCheck_compliance | 隐私检查 | 规范性 | 检查文档中是否存在敏感信息和不合规内容 | 严重 |
| StaticCheck_compliance | 敏感词检查 | 规范性 | 检查文档中是否存在敏感词 | 严重 |

### 术语检查

- 规则编号：1
- 规则项名称：StaticCheck_compliance_check
- 规则类型：规范性
- 规则级别：提示
- 参考资料路径：[terms-and-abbreviations.md](./terms-and-abbreviations.md)
- 位置：文档中所有文本内容，但排除代码块和代码片段内的内容。
- 规则：
   1. 术语存在性：术语和缩略语必须在参考资料[术语/缩略语]列和[产品名术语]章节中存在
      - 正例：UnalignRegForLoad（存在参考资料）
      - 反例：nalignRegForLoad（不存在参考资料）
   2. 大小写一致性：术语和缩略语的字母大小写必须与参考资料完全一致
      - 正例：UEFI、AllGather
      - 反例：uefi、allgather

### 隐私检查

- 规则编号：2
- 规则项名称：StaticCheck_compliance_check
- 规则类型：规范性
- 规则级别：严重
- 参考资料路径：无
- 位置：文档中所有文本内容。
- 规则：
   1. 个人隐私数据检测：严禁出现的隐私信息类型：
      - 工号：华为员工工号
        - 识别格式特征：首字母（可选）+ 8位数字
        - 具体模式：00+6位数字 或 01+6位数字；300+5位数字 或 600+5位数字；wx+5位数字；无首字母+8位纯数字
        - 示例：30012345、wx67890、00876543
      - IP地址：IPv4或IPv6格式
      - 个人姓名：中文姓名或外文姓名
      - 邮箱地址：符合邮箱格式的文本
      - 手机号码：11位手机号或国际电话格式
   2. 拼写错误：
      - 检查范围限定：仅检查参考资料中"拼写错误"章节明确列出的错误拼写单词
      - 检查逻辑：参考资料"拼写错误"章节包含"错误拼写 → 正确拼写"的映射列表；检查文档中是否出现参考资料中列出的错误拼写单词；如果文档中出现参考资料中列出的错误拼写，则报错；文档中出现的其他单词，即使有拼写错误但不在参考资料列表中，不进行检查
      - 示例：参考资料中包含"acsend → ascend"，则检查文档中是否有"acsend"，如有则报错；文档中有"mistake"但参考资料中未列出，则不检查"mistake"是否拼写错误
