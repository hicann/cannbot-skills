# docs-diagram-draw（CANN 文档自动绘图改图）

为 CANN 组织开源文档生成/修改符合[绘图规范](https://gitcode.com/cann/docs/blob/master/specification/drawing_specs.md)的技术配图。

- 新生成图片：直接输入自然语言描述，输出符合绘图规范的技术配图。

- 修改优化图片：支持规范化（推荐）和自定义改图能力，规范化指按照明确的规范和模板进行修改，自定义指特殊场景下按照用户的定制化要求进行修改。


**输出格式**：`.drawio.svg` ——含绘图副本（draw.io绘图软件打开可直接二次编辑）、嵌入图片、嵌入字体（跨环境显示一致）。改图时的输入也应为此格式。

## 如何使用

### 场景一：画一张新图

**你的输入**：用自然语言描述图的内容——类型、节点、流向、分组。建议说清四件事：

1. 图的类型（流程图 / 时序图 / 架构图 / 原理图…）
2. 有哪些节点/步骤（按顺序列出）
3. 怎么连接（谁到谁、判断分支的"是/否"走向）
4. 分组/层级（哪些属于同一组）

**输入示例**：

> 我要给 CANN 文档配一张 Ascend C 算子开发流程图：开始 → 环境准备 → 创建算子工程 → 编写核函数 → 实现 tiling → 编译算子 → 运行验证 → 结束。其中"实现 tiling"之后有判断"tiling 是否完成"，未完成则虚线返回"编写核函数"。要求符合仓库绘图规范。

**你得到的输出**：`<图名>.drawio.svg` 文件（文件名用英文小写+下划线，如 `ascend_c_dev_flow.drawio.svg`）——可直接放入文档仓；在 drawio 中打开可继续编辑。

### 场景二：规范化调整（推荐）

**适用**：图已存在，想让它符合 CANN 绘图规范，但不想逐项指定怎么改。

**你的输入**：给出图的位置 + 说明要规范化。会向你确认三个选择：

| 会被问到的选择 | 选项 |
| --- | --- |
| 颜色 | 按规范色板自动映射（推荐）/ 保持原色 |
| 字体 | 统一规范字体（推荐）/ 保持原字体 |
| 容器 | 画布宽度归档（推荐）/ 保持原尺寸 |

**输入示例 1——颜色、字体、容器都改**：

> docs/images/vec_add.drawio.svg 这张图帮我规范化一下，颜色、字体、容器都改。

（或等助手确认三个选择后回答："颜色自动映射，字体统一，容器归档"）

你会得到：`vec_add_normalized.drawio.svg` + 改动摘要，效果如下：

| 改动类 | 摘要示例 |
| --- | --- |
| 颜色 | 图内 4 种有彩色按优先级入板：深蓝→#5478FB（深底白字联动）、浅蓝→#C2D5FE、绿→#B0F0E2、红→#FEE2BA；描边统一 #686D75；黑白灰色块保持原样 |
| 字体 | 全部带文字元素统一 HarmonyOS Sans |
| 容器 | 画布宽度归 300 档（内容居中、四周留白归规范） |
| 其他默认类 | 线宽/虚线/箭头类型归一、内容节点加 4px 圆角 |

**输入示例 2——只改字体和容器（颜色保持不动）**：

> docs/images/vec_add.drawio.svg 规范化一下，只改字体和容器，颜色不要动。

（或确认时回答："颜色保持原色，字体统一，容器归档"）

你会得到：`vec_add_normalized.drawio.svg` + 改动摘要，效果如下：

| 改动类 | 摘要示例 |
| --- | --- |
| 颜色 | **零变化**——所有色块原样保留（选了"保持原色"） |
| 字体 | 全部带文字元素统一 HarmonyOS Sans |
| 容器 | 画布宽度归 300 档 |
| 其他默认类 | 线宽/虚线/箭头类型归一、内容节点加 4px 圆角 |

**你得到的输出**：`原图名_normalized.drawio.svg`——原图不动；确认改动方案后才执行，执行后附改动摘要（改了哪些类、多少元素）；未选择的类别（如示例 2 的颜色）与原图逐项一致。

**规范化会改什么**：填充色按优先级入色板（深色块→高亮色、浅色块→默认色，不同颜色不会归并成同一个）、描边统一、字体统一 HarmonyOS Sans、虚线/箭头类型归一、内容节点加 4px 圆角。**不会改**：文字内容、节点位置和大小、连线走向、黑白灰色块。

### 场景三：自定义调整（特殊场景）

**适用**：有规范覆盖不到的具体要求。

**你的输入**：哪个元素、改哪个属性、改成什么。说清楚三件事：

1. 改什么（元素的名字或位置描述，如"'矢量加法'这个节点"）
2. 改哪方面（颜色 / 文字 / 线型 / 位置大小 / 连线走向）
3. 改成什么值（如"深色强调"/"文字改成'数据搬运'"）

**输入示例**：

> docs/images/vec_add.drawio.svg 两处修改：1) "矢量加法"节点换成强调色（深色）；2) 第一个节点的文字"环境准备"改成"数据搬运"。其余不要动。

**你得到的输出**：改动前会看到一份**改动清单**（每处：哪个元素、哪个属性、现值 → 目标值、依据），确认后执行；执行后附改动摘要，并保证未提及的部分与原图逐项一致。

**可以改的**：填充色、描边色、文字色、字体、文字内容、线宽、虚实、箭头、圆角、节点位置/宽高、连线走向与锚点、画布尺寸。
**不能改的**（会说明原因并给替代建议）：删除/新增元素、改元素层级关系、更换形状、改文字对齐方式等——这类属于重新画图的范围。

## 环境依赖

| 依赖 | Windows | Linux |
| --- | --- | --- |
| drawio 桌面版 32.4.1（版本固定） | 自行安装（[v32.4.1 安装包](https://github.com/jgraph/drawio-desktop/releases/tag/v32.4.1)） | 可自行安装；未安装时自动下载（无需 root） |
| HarmonyOS Sans 字体 | 自行安装（[官方发布页](https://developer.huawei.com/consumer/cn/design/harmonyos-symbol/)下载 ttf 后双击安装） | 可自行安装（放入 `~/.fonts` 后执行 `fc-cache -f`）；未安装时自动下载并装入 `~/.fonts` |
