# aclnn 领域质检规则 - 完备性检查详细说明

**重要提示：**

- 仅使用本文件中明确定义的规则进行检查
- 规则名称、规则级别必须与本文件完全一致

## 2. 完备性检查

此类检查仅基于文档内容，不需要读取代码。

| 规则名称                 | 描述                                                             | 级别 |
| ------------------------ | ---------------------------------------------------------------- | ---- |
| 函数原型缺少使用场景说明 | 检查函数原型章节是否有两段式接口调用流程说明                     | 一般 |
| 返回码描述缺失           | 检查两段式接口的每个函数接口是否有返回值说明                     | 严重 |
| 一段接口参数拦截描述缺失 | 检查一段接口（GetWorkspaceSize）的返回值后是否有参数拦截校验表格 | 严重 |
| 确定性说明缺失           | 检查约束说明章节是否有确定性计算说明                             | 严重 |
| 缺少调用示例描述         | 检查调用示例章节是否包含编译运行说明和代码示例                   | 一般 |
| API 参数表里使用说明信息不完整 | 检查aclTensor/aclTensorList参数是否缺失空Tensor支持度说明，基础数据类型是否缺失取值说明或范围约束 | 提示 |
| 基本概念的固定 link 遗漏 | 检查两段式接口、非连续Tensor、broadcast关系、互推导关系、aclnn返回码、编译与运行样例等必选超链接是否存在且路径正确 | 提示 |
| API 功能说明缺少差异描述 | 检查多版本文档（带Vn）是否在接口功能中说明版本差异，以及aclnnXxxWeightNz是否阐述NZ格式参数 | 提示 |
| 未知变量含义缺失 | 检查功能说明中的计算公式、参数说明中的shape维度变量、约束说明中是否存在未解释的未知变量 | 提示 |

### 函数原型缺少使用场景说明

- 级别：一般
- 位置：检查位置在 `##函数原型`标题之下到具体函数代码段之间。
- 规则：检查是否有类似话术，只要能体现接口调用流程即可，"先调用 aclnnXxxGetWorkspaceSize，再调用 aclnnXxx"

### 返回码描述缺失

- 级别：严重
- 位置：每段函数接口
- 规则：无论哪一段接口，每段接口的每个 `## 函数接口`都需要有**返回值**。例如：`aclnnStatus：返回状态码，具体参见 [aclnn 返回码](../../../docs/context/aclnn 返回码.md)。`

### 一段接口参数拦截描述缺失

- 级别：严重
- 位置：必须归属在两段式接口的第一段 `aclnnXxxGetWorkspaceSize`接口的**返回值**后的下一行。
- 话术：必须在拦截表上方有使用场景说明。例如：`第一段接口会完成入参校验，出现以下场景时报错：`（语义类似即可）
- 表格：拦截表必须存在，且字段必须为{返回值、错误码、描述}

### 确定性说明缺失

- 级别：严重
- 位置：必须归属在 `## 约束说明`的段落里。
- 规则：必须有“确定性”关键字。例如：`- 确定性计算：\n\t - aclnnXxx 默认确定性实现`。

### 缺少调用示例描述

- 级别：一般
- 位置：必须归属在 `## 调用示例`的段落里。
- 规则：
  1. 必须有"编译与运行"类似的文字说明。例如：`示例代码如下，仅供参考，具体编译和执行过程请参考 [编译与运行样例](../../../docs/zh/context/compile_and_run_sample.md)。` 示例路径仅适用于相应目录层级，实际链接须相对待检文档所在目录解析。
  2. 必须要有代码段

### API 参数表里使用说明信息不完整

- 级别：提示
- 位置：API 参数说明表 - 使用说明列。
- 规则：
  1. 针对aclTensor、aclTensorList类型的参数，检查是否缺失"空Tensor支持度说明"相关内容。
  2. 针对基础数据类型（int64_t/float/double/bool）及其指针类型的参数，检查使用说明列对应内容中是否缺失“取值说明“或”范围约束”相关内容。

### 基本概念的固定 link 遗漏

- 级别：提示
- 位置：全文中各`## 标题`后面的超链接。
- 规则：必选参考资料的超链接必须存在且指向对应资料，非必选资料允许没有超链接。链接显示文字可使用中文，目标文件名及路径以目标仓库实际文件为准，不得因文件名不是中文或相对目录层级不同而判错。
  1.【必选】函数原型章节：两段式接口，ops-math 中对应 `docs/zh/context/two_phase_api.md`。
  2. aclnnXxxGetWorkspaceSize/aclnnXxx章节：
    a. 非连续Tensor：按目标仓库实际文件定位。
    b. broadcast关系：按目标仓库实际文件定位。
    c. 互推导关系：按目标仓库实际文件定位。
    d. 互转换关系：按目标仓库实际文件定位。
    e. TensorScalar互推导关系：按目标仓库实际文件定位。
    f.【必选】aclnn返回码，ops-math 中对应 `docs/zh/context/aclnn_return_code.md`。
  3. 【必选】调用示例章节：编译与运行样例，ops-math 中对应 `docs/zh/context/compile_and_run_sample.md`。
  4. 所有链接可以是 Markdown 语法，也可以是 HTML 语法。检查相对链接时，以待检文档所在目录为基准解析目标路径，确认目标文件存在且内容对应所需参考资料，不固定要求 `../../../` 层级。其他仓库按其实际文件布局检查。
  5. 无法读取目标仓库或目标资料时，不得仅凭文件名猜测链接错误；必选链接是否存在仍可检查。

### API 功能说明缺少差异描述

- 级别：提示
- 位置：`## 功能说明`中的`接口功能`部分
- 规则：如果当前文档是多版本（文档大标题带Vn）就需要在`接口功能`中说明版本差异：
  1. 多个V版本接口之间，Vn必须要阐述与Vn-1相比，新增什么能力。（要求高版本兼容低版本）
  2. 如有aclnnXxxWeightNz，则须阐述哪些参数要为NZ格式。

### 未知变量含义缺失

- 级别：提示
- 位置：
  1. `## 功能说明`章节中的`计算公式`是否含有未解释的未知变量。
  2. `## （函数接口）`中的`参数说明`表格里的`使用说明`列中，关于"shape 维度变量"是否含有未解释的未知变量。
  3. `## 约束说明`章节中是否出现在全文中未出现未解释的变量。
- 规则：检测上述位置中是否有未知变量。
- 示例：
  1. 驼峰和snake格式的变量视为不同变量，例如opName和op_name。
  2. 计算公式为：$$A = QR$$，如上下文未提及则需解释A、Q、R分别指代什么。
  3. 接口函数参数说明的使用说明中写道"shape为[B, S, H]",如上下文未提及则需要解释B、S、H分别指代什么。
