# aclnn 领域质检规则 - 可读性检查详细说明

**重要提示：**

- 仅使用本文件中明确定义的规则进行检查
- 规则名称、规则级别必须与本文件完全一致

## 3. 可读性检查

此类检查仅基于文档内容，不需要读取代码。

| 规则名称                         | 描述                                                                  | 级别 |
| -------------------------------- | --------------------------------------------------------------------- | ---- |
| 一段接口参数拦截前后参数名一致性 | 检查拦截表格中描述列的参数名是否与参数说明中的参数名一致              | 严重 |
| API 名称前后文一致性             | 检查 API 名称是否与标题、函数原型、接口标题、调用示例等上下文保持一致 | 严重 |
| 产品支持度一致性                 | 检查产品支持情况列表与后文芯片差异化描述是否一致                      | 严重 |
| 确定性说明不符合固定话术 | 检查确定性计算说明是否使用三种固定话术之一（默认实现/支持开启/不支持开启） | 提示 |
| API 参数信息描述冗余 | 检查参数说明表中使用说明列与数据类型/数据格式/维度列是否语义重复，以及与约束说明章节是否重复 | 提示 |

### 一段接口参数拦截前后参数名一致性

- 级别：严重
- 位置：第一段接口（aclnnXxxGetWorkspaceSize）的**返回值**拦截表格的"描述"列中用到的的参数名必须与**参数说明**里的参数名一致。
- 规则：**检查方法：**
  1. 找到参数说明表中的参数名列表
  2. 找到拦截校验表"描述"列中提及的所有参数名
  3. 对比两者是否一致（不包括“tensor”）

### API 名称前后文一致性

- 级别：严重
- 位置：全文中的所有 API 名称，例如："Xxx"
- 规则：
  1. 与文章一级标题一致（# aclnnXxx）
  2. 与函数原型一致（aclnnXxxGetWorkspaceSize，aclnnXxx）
  3. 与一阶段接口标题一致（aclnnXxxGetWorkspaceSize）
  4. 与二阶段接口标题一致（aclnnXxx）
  5. 与二阶段接口参数说明表中"workspaceSize"参数的"描述"中"由第一段接口 aclnnXxxGetWorkspaceSize 获取"一致
  6. 调用示例里“中文注释”和“LOG_PRINT”的所有 Xxx 保持一致（// 调用 aclnnXxx 第一段接口）

### 产品支持度一致性

- 级别：严重
- 位置：`## 产品支持情况`内容与文中其他内容。
- 规则：文中所有章节的产品差异化描述要与 `## 产品支持情况` 列表内容一致，**逐一检查以下两项**：
  1. **不支持的产品不得出现差异化描述**：在 `## 产品支持情况` 中标记为"不支持"的产品，不得在 `## 约束说明` 或其他章节中出现任何差异化描述（包括"不支持XX数据类型"等补充说明）。如果产品整体不支持该接口，就不应再为其单独阐述约束细节，否则造成前后矛盾。
  2. **支持的产品差异化描述必须与支持列表一致**：在 `## 产品支持情况` 中标记为"支持"的产品，其后文的差异化描述（如"不支持BFLOAT16"）必须是该产品在该接口下的真实约束，不得出现与支持列表矛盾的描述。
- 检查方法：
  1. 从 `## 产品支持情况` 中提取所有标记为"不支持"的产品名称列表，在 其他章节中逐一搜索这些产品名称是否出现，若出现则报错。
  2. 从 `## 产品支持情况` 中提取所有标记为"支持"的产品名称列表，确认后文的差异化描述仅针对这些产品。
- 示例：
  1. **反例（不支持产品出现描述）**：产品支持情况中 `<term>Atlas训练系列产品</term>`标记为不支持，但约束说明中出现 `<term>Atlas训练系列产品</term>：输入参数不支持INT64。` —— 前后矛盾，应删除该约束描述。
  2. **反例（支持列表与描述矛盾）**：产品支持列表里 `<term>Atlas 200I/500 A2推理产品</term>`标记为“不支持”，但下文出现 Atlas 200I 产品的差异化描述。
  3. **正例**：产品支持列表中标记为"支持"的产品，约束说明中写 `<term>Atlas A2系列产品</term>：不支持BFLOAT16。` —— 这是对支持产品的真实约束补充，前后一致。

### 确定性说明不符合固定话术

- 级别：提示
- 位置：`## 约束说明`章节
- 目标：检查确定性计算相关说明是否使用了以下固定话术，未使用则报错
- 规则：确定性计算有且仅有以下三种固定话术，三选一：
  1. aclnnXxx默认确定性实现。
  2. aclnnXxx默认非确定性实现，支持通过aclrtCtxSetSysParamOpt开启确定性。
  3. aclnnXxx默认非确定性实现，不支持通过aclrtCtxSetSysParamOpt开启确定性。

### API 参数信息描述冗余

- 级别：提示
- 位置：`## （函数接口）`中的`参数说明`表格。
- 话术：
  1. 检查`使用说明`列和`数据类型`、`数据格式`、`维度(shape)`列的语义是否重复。
  2. 检查参数表与`## 约束说明`章节的内容是否有重复。
