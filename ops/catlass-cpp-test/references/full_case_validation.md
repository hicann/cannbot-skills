# 全量用例设计

本规则用于 05 阶段 V1 全量验收。用例使用算子工程现有测试框架和格式生成，
不为本阶段引入新的测试后端。

## 输入

- `docs/api.md` 声明的支持范围和非法输入行为；
- `docs/design.md` 中的计算分支、边界处理和有效区域；
- 当前实现、CPU 标杆和冻结的精度策略；
- 算子工程已有测试入口和用例格式。

## 覆盖规则

1. 覆盖接口支持的 shape、dtype、layout、属性、可选输入和输出组合。
2. 覆盖设计与实现中的计算分支、tail、对齐边界及接口声明的非法输入。
3. 连续范围按等价类选择代表值，并覆盖边界值和边界相邻值。
4. 相互独立的多维取值使用组合覆盖控制规模；存在语义关联的组合单独保留。
5. 每个支持项和运行分支至少对应一个用例，不以固定用例数量代替覆盖证明。
6. 正式验收集中的用例全部执行，不再抽样。

## 输出

按工程现有格式生成全量用例，并在 `docs/validation.md` 记录覆盖项、来源、
取值或分支、对应工作流用例、执行证据和结论。精度结果按冻结的
`reference/precision-policy.json` 判定。
