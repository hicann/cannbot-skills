# 精度验证（迁移场景）

> 阶段 4 的操作手册。**阈值与标杆构造方法以 `ops-precision-standard` 为唯一真源**，本文只补迁移特有的用例设计与失败分诊。

## 1. 前置

- GATE-3 已通过（BUILD/INSTALL 均 PASS）。
- 被测实现通过**真实算子接口**调用（aclnn / `torch.ops.npu.<op>`），禁止用 PyTorch 同名算子替代被测实现。
- 被测 dtype 清单与阶段 1 决策一致（被迁移的 dtype 必须有对应用例，被判定不支持的 dtype 必须显式跳过并记录）。

## 2. 标杆（golden）怎么来

| 来源 | 何时用 | 注意 |
|---|---|---|
| CPU 高精度实现（numpy/torch float64 或更高精度算法） | 默认 | 必须按算子的真实语义实现，含边界分支 |
| 昇腾小算子拼接（高精度组合） | 语义复杂、CPU 实现成本高 | 需说明拼接算子与原算子的等价性 |
| **A5 实测输出** | **不能作为标杆** | 跨架构 FTZ 差异使其只能作为"行为参考"，不能作为验收基准 |

golden 构造完要做一次**自检**：用 CPU float32 与 float64 互相验证，确认实现本身没有精度缺陷，再拿去比 NPU。

## 3. 用例矩阵（≥30 例，单例元素数 ≤200K）

| 维度 | 覆盖要求 |
|---|---|
| dtype | 每个 A2 支持的 dtype 至少 2 例；**每个被迁移的 dtype 至少 3 例**（正常值、极值、边界） |
| layout / 排布 | 连续 / 非连续 stride / ND/NZ 转换路径 / 对齐与非对齐尾块 |
| shape | 最小（1 元素、1 行）、典型、非对齐（含 1/3/7 余数）、多核切分边界（核数与 tail 不整除） |
| 特殊值 | 0、±max、subnormal（见 §4）、Inf/NaN 按算子约定、空张量（若支持） |
| 确定性 | 同一输入重复执行 ≥3 次，输出必须一致（排查同步/竞争类错误） |
| 量化路径 | scale/zero-point 边界：最大 scale、scale=0（若语义允许）、饱和边界 |

**迁移特有必测项**：

1. **FTZ 回退**：A5 上被清零的 subnormal 结果，A2 应恢复为非零。构造 `Exp/Ln/Sqrt/Rsqrt/Div/Reciprocal` 输入含 subnormal，或中间结果落入 subnormal 的用例。
2. **dtype 迁移等价**：fp8/hif8 → bf16/fp16/int8 时，golden 要按"迁移后的语义"算（例如先反量化再计算），并单独报告"与 A5 原 dtype 输出的差异"作为参考信息，不作为失败判据。
3. **恢复项**：int4/4:2 稀疏、ZZ 分形路径恢复后，必须有用例覆盖这些路径（否则等于没验证）。
4. **workspace 中转路径**：L0C→UB 改为 GM 中转后，覆盖 `workspace` 复用、多 tile 连续写、tail tile 的场景。
5. **多核尾核**：核数不整除的 shape，验证尾核不越界、不重复写。

## 4. subnormal 用例设计

- 用 `numpy.nextafter(0, 1)` / 手工构造 `1e-40`（fp32）、`6e-8`（fp16 的极小 subnormal）等值。
- 记录每个用例的输入分桶：normal / subnormal / zero。
- 预期：A2 不因 A5 的 FTZ 被清零；若仍出现清零，说明代码里还残留 A5 的规避（eps 或 algo 分支）没有删干净，回到阶段 2。

## 5. 失败分诊（先分类，再改代码）

| 现象 | 可能原因 | 判别方法 |
|---|---|---|
| 仅在 subnormal 域偏差、误差 ≤ 数 ulp | dtype 表示粒度 / FTZ 差异 | 按输入分桶统计，看是否集中在 `|golden| < tiny` 域 |
| 大范围偏差 | 算法/索引/同步错误 | 缩小到最小 shape，逐步二分 |
| 尾块处偏差 | count/mask 处理错误、`DataCopyPad` 漏用 | 用"整倍数 shape vs 非整倍数 shape"对照 |
| 偶发偏差、重复执行不一致 | 同步缺失/竞争、workspace 复用 | 重复执行 10 次统计不一致率 |
| 全 NaN / Inf | 除零、溢出、未初始化 buffer | 先查除零与 buffer 初始化；**NaN/Inf 必须根因定位后才能结束** |
| 仅在特定 dtype 失败 | Cast 舍入/饱和语义映射错误 | 打印中间结果，逐步比对 Cast 前后 |
| 大 shape 失败、小 shape 通过 | UB/L0C 预算或 tiling 越界 | 关掉双缓冲/缩小 tile 复测 |

**禁止**：用"硬件差异"一句话结束分诊；用调阈值、删用例、缩小 dtype 覆盖来"通过"。

## 6. 条件接受（仅限非缺陷差异）

当且仅当满足以下全部条件，才可走条件接受：

1. 根因已定位并归类为"非缺陷"（dtype 表示粒度、A5/A2 数学库实现差异等）；
2. 给出证据：超标元素数、占比、最大绝对误差、分桶结果；
3. 用户明确表示接受（记录原话/结论）；
4. 报告输出 `CONDITIONAL` + `USER_ACCEPTED`，保留实际通过数与豁免明细。

**不可条件接受**：NaN/Inf、公式错误、大范围偏差、同步导致的偶发错误、因删代码导致的精度劣化。

## 7. Gate 输出规则

```
[GATE-4] PRECISION=30/30_PASS
[GATE-4] PRECISION=27/30_PASS BLOCKED      # 有 3 例失败，附失败清单与分诊结论
```

- 报告必须附：用例清单（id、dtype、shape、layout、通过/失败）、失败用例的误差统计、分诊结论、标杆版本。
- 只跑子集时输出实际分子分母，不能写 `PASS`。

## 稀疏注意力 / 反向算子的专项口径

- 输出分项：`attn_out`、`softmax_max`、`softmax_sum`（LSE 分母）分别计算 `matched_ratio`，任一项低于阈值即失败；
- 布局/模式组合：至少覆盖 `BSND` 与 `PA_BSND`、`sparse_mode=3`、`lse=0/1`、fp16/bf16；
- 反向算子：用仓库 pytest（`test_*_grad`）或 golden 梯度比对，禁止用接口返回码代替精度结论。
