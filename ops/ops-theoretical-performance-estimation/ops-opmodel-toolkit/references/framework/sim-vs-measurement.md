# 模型与设备实测比较

输入为同一数学语义、case、实现和硬件下的模型结果与设备记录。
设备记录应包含 dtype/layout、编译与运行环境、频率、计时范围和重复实验方式。

模型周期换算使用本次 profile 的时钟；完整 case、单核与局部阶段分别比较。
先确认工作量、输出、成本来源和统计范围，再报告模型与实测的数值及误差。
保留噪声、尚未校准参数和未覆盖行为，不用一个端到端误差任意修补所有成本。

修改参数或候选后，重新运行同口径的模型与设备测试。模型周期降低不自动证明
设备加速；数值正确、性能收益和成本校准分别报告。

## 实现成本与硬件参数的边界

先核对总 case、活跃核、计时边界、实际流量与计算量，再核对实现、编译环境及
生产消费／下发关系。成本按具体实现绑定，低效实现的测量不代表硬件服务率低。
整算子残差不能唯一拆成 VF、带宽和排队费用；证据不足时保留未解释偏差或假设，
不统一降低带宽或把等待回填物理延迟。只有独立受控证据支持时才考虑修订共享硬件
参数，并以未参与辨识的场景验证。更换模型或成本后统一重评；用户只请求模型工作时
不自动扩展为校准任务。
