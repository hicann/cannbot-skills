# DAG 方案寻优

按起点读取[已有 DAG](agent-dag-opt/existing-dag.md)或[公式入口](agent-dag-opt/formula-entry.md)；
比较、排名及停止条件见[证据规则](agent-dag-opt/evidence.md)。
接口与限制按需查[框架搜索参考](framework/index.md)。

用于固定 DAG 配置搜索，或从公式及已有模型探索不同结构、映射和实现族。代理负责提出
假设与选择实验，wheel 提供模型运行、检查和搜索接口。

## 从比较契约开始

固定完整 case、权重或逐 case 目标、硬件与成本、数值标准、计时范围和预算。
已有算子实现保留生产对照；尚未实现时从公式建立独立参考，并按[新算子建模](new-operator.md)
恢复一个可运行起点。没有生产基线时不报告相对生产实现的收益。

根据数学依赖与硬件提出有区别的实现族，例如融合/物化、驻留/重计算、归约组织、
分核或数据通路变化。每个候选记录父候选、来源、收益机制、新增搬运/同步/存储代价、
适用条件和失败信号。只改变模板参数时如实说明结构空间未探索。

## 选择搜索入口

完整路由见[搜索器接入](agent-dag-opt/search-integration.md)。

| 任务 | 入口与核对项 |
| --- | --- |
| 固定图 tile/阶段/slots | `dag_run` 或 `joint_search`；声明参数和合法阶段域 |
| 分核 | `split_run`；保留任务原子性、状态顺序和输出归属 |
| 图动作发现/应用 | `graph_search --actions` / `--apply-action`；以实际帮助和可用动作给出参数 |
| 已声明候选与实验 | `graph_search --experiment`；使用当前模型支持的实验类型 |
| 多轮记录 | `agent_search`；登记假设、候选快照、评价、保留/暂缓与结束原因 |

实际命令见[wheel 命令](joint-optimization/wheel-commands.md)。
动作调用与候选输出见[图搜索接口](framework/graph-search.md)。

## 逐轮推进

1. 保存固定基线及有效参数，从数量、trace、容量和任务分配找限制。
2. 选择能区分假设的最小变化，物化完整候选目录；结构变化核对语义覆盖、状态、
   区域与别名、通信、缓冲消费者和释放。只换候选名字不构成新方案。
3. 适用时实际调用内置搜索器探索族内配置，记录固定/不支持/未覆盖维度。
   对手工候选进行比较不等于自动搜索完整族内空间。
4. 用相同 case、硬件、成本、缓存假设和 scope 比较。局部、原生、物理和图代理结果
   不混排；缺少有效成本的候选保留为待验证假设。
5. 将领先候选导出到用户目录，用支持的完整 case 路径重新加载、复评，核对身份和
   实际有效参数。保留反例和次优但有辨别力的方案。

核对候选的完整接口覆盖：主输出、辅助输出、状态、模式和用户 VF 均对照
`SEMANTICS.md`，数学参考、实现精度参考、执行回放与设备结果分别记录。
动作被接受不表示产生了新效果，构造通过也不代表数值通过。导出后核对语义、规格与
运行文档的完整性；变更参数或硬件时从源模型重新生成绑定快照。

候选包含新增或修改的 VF 时，按[联合流程](joint-optimization/workflow.md#候选与测前预测)
核对成本来源、适用域及对应入口的排名资格；缺少匹配证据的候选保留未验证状态。

目标来源、配置、依赖及修订按[目标接口](framework/objectives.md)记录。
仅换目标先复用有效原始观察重评分，业务结果、原始周期和各项资格分开；并列保留整组。
多 case 使用同配置或[统一规则](framework/policies.md)的完整评价，不拼接逐 case 赢家。
场景、运行时控制或状态区域重构按[支持范围](framework/runtime-control.md)核对。
连续若干轮无改善只支持本轮停止，不证明全局收敛。

## 会话和结束

多轮会话可使用 `propose/register/evaluate/note/retain/defer/close`；按实际帮助
填写参数。会话契约与候选快照冻结，原目录修改不会更新已登记候选。
`scored` 仅是评价状态，不能代替数值、成本或设备验证；关闭会话也不认证全局最优。

预算耗尽记录未完成覆盖；有可复现改善时说明适用范围；同一机制反复失败且无新证据时
保留反例并转向其他假设。请求包含真实实现时，继续[联合寻优](joint-optimization/guide.md)，
用同口径设备结果决定是否采用。

新建模型和新一轮独立评估默认普通带宽，细化按需显式选择；借用搜索入口不切换
调用方模型。固定硬件比较实现，缺少 VF 实测可先按[VF 成本约定](framework/vf-costs.md)
估算并进行探索性搜索。匹配实测回填后重评；普通模型无法区分的搬运形态保留代表
候选和未覆盖机制，不由同分或当前排名断言设备表现相同。
