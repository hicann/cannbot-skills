# OpModel 使用指南

OpModel 用模型描述算子的计算、搬运、任务分配和资源约束，在本地仿真其执行，
生成可分析的结果，并搜索可行的参数或分核方案。核心能力由安装的 `opmodel` 包提供。
自己的模型、实验配置和结果保存在用户工作目录中。

## 第一次使用

1. [安装与环境](install.md)：从 PyPI 安装，准备文档、示例和工作目录。
2. [快速入门](quickstart.md)：复制一个模型，运行完整 case 并查看结果。
3. [编写自己的模型](modeling.md)：理解六份定义文件，修改形状、分块和 Python hooks。
4. [仿真与模型校验](simulation.md)：选择入口，设置输入和输出，处理无效模型。
5. [分析结果](analysis.md)：解读周期、流水线、搬运量与 trace。
6. [参数寻优](optimization.md)：运行搜索、读取候选、应用方案并重新仿真。

主线采用同一个可编辑的[矩阵乘示例](../assets/examples/matmul/README.md)。教程中的命令
均从用户项目目录运行，并通过 `OPMODEL_SKILL_DIR` 定位本 skill，使用 `work/` 保存结果。
重复运行时选择新的输出目录。
