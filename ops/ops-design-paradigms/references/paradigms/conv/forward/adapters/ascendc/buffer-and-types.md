# 类型与 buffer 基线

## 1 L0C 累加类型（决定 Mmad / Fixpipe 模板参数）

### 1.1 取值基线

| 输入 dtype | L0C 累加类型 | Mmad 调用形式 | Fixpipe 调用形式 |
|-----------|-------------|--------------|----------------|
| **fp16**（基线，生成代码默认） | `float` | `Mmad<float, half, half>` | `Fixpipe<half, float>`，quantPre = `F322F16` |
| bf16 | `float` | 同上 | 同上 |
| int8 / 量化 | `int32_t` | `Mmad<int32_t, int8_t, int8_t>` | `Fixpipe<half, int32_t>`，quantPre = DEQF16 类，配套 scale 装载 |

### 1.2 版本差异警告

| 项 | 说明 |
|----|------|
| 历史版本行为 | 部分编译环境对 fp16 采用 `int32_t` + 定点移位机制——依赖特定编译器内建指令，**不可移植** |
| 生成代码规则 | **一律按上表基线组合书写**，不引入定点移位类非基线机制 |
| 不匹配的表现 | 编译期直接报错（mad 重载缺失），不会带病运行 |
| 真值来源 | 以所用头文件树的实际定义为准，编译前核实 |

## 2 TPosition ↔ 物理 buffer 与管理原语

### 2.1 对照表

| TPosition | 物理 buffer | 管理原语 | 卷积用途 |
|-----------|------------|---------|---------|
| A1 | L1（A 侧区） | `TQue<A1>`（需跨流水同步）或 `TBuf<A1>`（一次性驻留） | fmap 2D 图、bias 全量 |
| B1 | L1（B 侧区） | `TQue<B1>` | weight NZ 分形块 |
| A2 | L0A | `TBuf<A2>` | Mmad 操作数（A 矩阵分形） |
| B2 | L0B | `TBuf<B2>` | Mmad 操作数（B 矩阵分形） |
| CO1 | L0C | `TQue<CO1>`（自动串接 M→FIX 依赖） | 累加结果 |
| C2 | BT | `TQue<C2>` | bias 装载 |

### 2.2 选型速查（TQue vs TBuf）

```
                     数据在 buffer 内的生命周期
                     ┌─────────────────┬─────────────────┐
                     │  一次性驻留      │  循环装载/消费    │
        ┌────────────┼─────────────────┼─────────────────┤
        │ L1（A1/B1）│  TBuf（全载态）  │  TQue（流式态）  │
        ├────────────┼─────────────────┼─────────────────┤
        │ L0（A2/B2）│  TBuf（常见）    │  TBuf + 手写事件 │
        ├────────────┼─────────────────┼─────────────────┤
        │ L0C（CO1） │       —         │  TQue（自动串接）│
        ├────────────┼─────────────────┼─────────────────┤
        │ BT（C2）   │       —         │  TQue            │
        └────────────┴─────────────────┴─────────────────┘
```

## 3 平台能力真值的查询位置

| 项 | 说明 |
|----|------|
| 真值来源 | 编译环境的**系统常量头**（sys_constants 类）与算子公共头文件的常量区 |
| 包含内容 | 各级容量（L1 / L0A / L0B / L0C / UB / BT）、分形粒度（M0 / N0 / K0） |
| 跨 SoC 移植 | 以目标 SoC 的系统常量头为**唯一真值**；替换示例代码中的 dav-3510 常量后**重算全部容量不等式** |
| L1 预留余量 | 示例取 4KB，用于覆盖 bias L1 驻留与对齐碎片，可按实际布局收紧 |
