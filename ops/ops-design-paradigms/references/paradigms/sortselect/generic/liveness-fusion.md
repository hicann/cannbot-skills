# SortSelect 数据存活与融合

| 数据 | 存活范围 | 复用条件 |
|---|---|---|
| 原始 value | 搬入至结果恢复；按索引回读时需保留原输入 | 最后一次恢复读取完成 |
| 单调 key | 局部排序或全部 Radix 轮次 | 当前轮消费者完成 |
| 原轴 index / 排列映射 | 从逻辑恒等映射贯穿重排或排列组合直到输出 | values 和 indices 均恢复完毕；间接表示的前序排列须读完 |
| 两阶段逆映射 / 行号键 / 紧凑键 | 第一阶段输出至第二阶段恢复 | 恢复完成 |
| 有序 run | 产生至下一层归并读完 | 下游不再消费该 run |
| 桶计数 / 前缀状态 | 当前 digit 统计至散射完成 | 当前轮所有参与者结束 |

按同时存活区间安排 buffer，输入输出有重叠时必须单独证明没有未读数据被覆盖。归并和 Radix 的 ping/pong 不能在同一轮随意别名；奇偶轮决定最终输出所在 buffer。

可融合的边界包括搬入时构键和初始化索引、最终写回时恢复原值和转换索引类型。原始 payload 通过索引恢复能保留浮点位模式，但增加一次输入读取，应与直接携带 value 的方案比较。

## 统一批次内存

以下规则适用于全部输出配置。M 为总行数，B 为当前 UB 批次行数，P_act 为长轴当前活跃行数；D、Jtmp、Jout 分别为值、中间索引、输出索引字节数，L 为输出轴长。

| 空间 | 规模与释放/复用边界 |
|---|---|
| 最终输出 | 每个所需字段 M×L；values 为 D 字节、indices 为 Jout 字节 |
| 必要的非尾轴输入转置 | M×N×D；排序和最后一次原值回读完成后释放；顺序等价时不分配转置区 |
| 必要的非尾轴输出转置 | 各字段 M×L；逆转置完成后释放；按 L 独立判断，顺序等价时不分配转置区 |
| 核内工作集 | B 行的值、键、索引、转换、scratch 与对齐之和，不超过实际 UB |
| 长轴工作区 | 所需 ping/pong 各按 P_act×N 及实际类型预算；桶、状态、run 按当前行/块/参与者预算 |
| 系统保留 | 单列运行时 workspace、UB 保留与对齐，不当作算法可用空间 |

当前行/批次完整排序后，在最后恢复/写回中应用 [输出区间](output-mapping.md)，再复用 UB 或外存临时区。不为未处理或已完成的行保留无消费者的 M×N 排序结果。Sort 的最终输出本身为 M×N，属于接口输出；transpose 输入也为 M×N，属于布局缓冲，均不与 scratch 混算。

跨批次 scratch 使用固定基址和批次内行号；输入、最终输出使用全局行号。上一批最后读写及所有同步完成后，下一批才能覆盖同一空间。中间索引、计数/状态和最终输出索引各自核对范围；更改宽度时同步修改模板、pitch、预算与地址。

验证包含多批次、尾批、更新输入后重复运行、输入未修改，以及固定 N/并行度后增大 M 的空间变化。最终输出与布局缓冲可以随 M 增长，排序 scratch 按固定 B/P_act 复用。设备峰值须说明相对调用前驻留输入的基线，并区分活跃分配、缓存池与系统占用。

内存复用同时核对原有提交粒度与性能基线。参考 example 尚未落实有界 P_act 时，在语言适配层明确登记实际分配规模与缺口；不能以增加 Host launch 或未经性能验证的 kernel 批次循环，直接替代已验证的执行方式。目标设计与参考实现状态分别说明。
