# SortSelect 同步模型

同步必须对应数据依赖和实际参与者，具体原语由语言适配层确认。

| 阶段 | 必须建立的依赖 |
|---|---|
| 批次搬入 → 插入排序 | 所有参与线程完成共享存储写入后才能读取 |
| 插入 / 两阶段恢复 → 写回 | 排序及逆映射写入完成，写回才能消费 |
| run 排序 → 归并 | 输入 run 完整发布，归并才能读取 |
| 归并轮次 → 下一轮 | 当前输出写入完成，且旧输入不再被消费，才可交换 buffer |
| Radix 计数 → 前缀 / 散射 | 桶计数和块内秩可见；前缀发布后才可计算目标地址 |
| Radix 散射 → 下一 digit | 全序列目标 buffer 完成写入，下一轮才能读取 |
| 写回 → 批次复用 | 消费者结束后才能覆盖共享存储 |

采用带状态的 lookback 协议时，块间计数与前缀按以下状态规则发布。每个桶的计数与状态编码在同一个 uint32/int64 状态字中一起发布（高两位为状态、低 30/62 位为数值），不拆成独立的计数写入与标志写入。等待方须区分局部计数与完整前缀，并确认读到有效状态后再使用数值。不能把该协议简化成普通标志轮询。

块级 barrier 必须被该块全部线程按相同次数到达。尾行和尾元素可屏蔽读写，但不可因此跳过其他线程仍会执行的 barrier。各原语的线程参与范围由对应语言适配层说明。
