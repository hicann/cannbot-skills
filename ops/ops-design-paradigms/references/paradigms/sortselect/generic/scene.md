# SortSelect 场景与边界

沿指定轴重排 value/index，或从有序序列取顺序统计量。

| 操作 | 输出 | 需明确的契约 |
|---|---|---|
| Sort | 排序值及原轴索引 | 方向、稳定性、NaN、零符号、索引类型 |
| Argsort | 原轴索引 | 同 Sort，仍需要排序键 |
| TopK | 前 K 个值及索引 | largest、sorted、K 的合法域、输出轴长 |
| KthValue | 第 K 个值及索引 | K 的编号起点、相等值索引规则、keepdim |

当前主体提炼连续尾轴全排序：小轴插入、小轴两阶段、常规核内归并、单核及多核 Radix。原输入布局由调用层规范化；主体路由取决于 dtype、轴长、序列数和片上容量，不能仅按轴长排序几个阈值。

所有接口按 [统一输出映射](output-mapping.md) 配置名次区间和输出字段；完整排序域仍为 N，不按算子名称改变排序主体或布局规则。

## 选择操作的契约

先继承目标框架或算子规格；以下是全排序基线的可选行为，不覆盖已有接口约定。

| 项目 | 生成时需落实的行为 |
|---|---|
| K 的合法域 | TopK 若采用 0≤K≤N，则 K=0 返回轴长为 0 的 values/indices，无需启动计算；Kth 的编号起点及合法域另行确定 |
| `sorted` | True 要求按指定方向输出；若 False 仅表示不要求排序，则有序结果也满足契约，可复用全排序基线 |
| 相等键 | 可采用原轴索引较小者优先的稳定规则；若只要求任意有效 TopK，不能强求与 builtin 的平局索引次序相同 |
| NaN 与正负零 | 明确 NaN 的排序位置、不同表示是否同键、原值位模式是否保留，以及零是否等键；键归一化与输出值归一化是不同操作 |
