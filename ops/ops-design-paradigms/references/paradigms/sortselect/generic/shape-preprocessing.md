# SortSelect shape 预处理

1. 校验 rank、dtype、axis；负 axis 加 rank。标量、空输入和选择参数按目标接口处理。
2. 将公共接口转换为 [统一输出参数](output-mapping.md)：方向、`first_rank`、输出长度 L、输出字段及最终 shape。
3. 对连续输入合并轴前、轴后维度，得到 `[O,N,I]`，独立行数 M=O×I。非连续输入先物化连续张量；不能将连续公式直接用于任意 stride。
4. 用足够宽的整数检查维度乘积、字节数、索引、计数、状态编码与循环增量，防止地址合法但最后一次增量回绕。
5. 按下节判定规范化为连续 `[O,I,N]`，排序主体只处理尾轴。连续尾轴及等价布局直接使用或 reshape；只有元素排列需要变化时才物理 transpose。
6. 主体输出 `[O,I,L]`，按各输出的实际布局判定是否逆 transpose 为 `[O,L,I]`，顺序等价时直接 reshape，再按接口恢复 shape。索引仍是原轴坐标，无需重新编号。

调用层输入原布局偏移为 `(o*N+j)*I+i`，输出为 `(o*L+t)*I+i`；尾轴主体分别使用 `r*N+j`、`r*L+t`。输入和输出 pitch 独立，不能把 N 沿用到输出。

## 物理转置的判定与验收

“非尾轴统一 transpose”表示不再按长轴/短轴设计不同的非尾轴排序模板，统一在调用层完成必要的布局规范化。它不要求每次调用都启动 transpose；排序模板选路仍使用原有 dtype、轴长、行数和资源条件。

以下条件适用于已物化连续、非空的普通张量，采用上述 `[O,N,I]→[O,I,N]` 三维折叠并保留非选择维的相对顺序；标量和空输出先按接口处理。I 是原选择轴之后各维度的乘积，N 是输入轴长，L 是输出轴长。

| 布局操作 | 需要物理 transpose 的条件 | 其余情况 |
|---|---|---|
| 输入 `[O,N,I]→[O,I,N]` | `N>1 && I>1` | 直接使用或等价 reshape，零布局转置 kernel |
| 每个输出 `[O,I,L]→[O,L,I]` | `L>1 && I>1` | 等价 reshape，零布局转置 kernel |

原选择轴为尾轴时 I=1，输入及全部输出均必须跳过物理转置；轴后仅 singleton 的情况同样如此。N=1 时输入布局也等价。输出条件使用 L，不能直接复用输入的转置标志：例如 L=1 时，输入可能需要转置，输出仍只需 reshape。仅为交换 singleton 维度而分配转置缓冲、启动 transpose，或以 `rank>0` 作为转置条件，均不符合本规则。

若沿用参考代码中直接交换原轴与末轴的高维置换，须按实际置换检查内存顺序；它可能同时重排非选择维，不能脱离上述三维折叠条件，仅凭 N=1 或 L=1 就省去转置。

例如 `[512,16384]` 沿尾轴处理时，可直接作为 `[512,16384]` 连续行；即使使用三维元数据，`[512,16384,1]→[512,1,16384]` 也只需 reshape。`[2,5,3]` 沿中轴处理则需将输入物化为 `[2,3,5]`；若 L=1，输出 `[2,3,1]→[2,1,3]` 只需 reshape。

设计、编码与验收须对照上述条件，核对实际调用图或设备记录中的布局转置次数：尾轴及等价布局为零；真正改变排列的输入、输出各按需转置一次。只检查数值精度不能证明没有冗余布局操作。非连续输入的必要连续化或输出 view copy 另行核对，不混作布局转置。

布局缓冲仅为实际需要的物理转置分配，与排序 scratch 分开预算，性能包含实际发生的转入、排序和输出还原。元素排列确需变化时，仅修改 shape 或生成非连续 view 不等于完成 transpose。实际包装和现存实现限制见命中适配层的布局说明。

## 分层测试契约

- 接口测试从原始 shape/axis 进入，验证调用层的条件转置、尾轴排序及输出还原，并核对实际布局操作与上述条件一致。
- Kernel 白盒验证尾轴主体，使用完成相同布局规范化后的连续输入及尾轴参数。例如 `[4,8,4], dim=1` 先物化为连续 `[4,4,8]`，再以 `dim=-1` 进入主体；输出按 L 恢复接口布局。原始用例及其与规范化用例的映射保留。
- 分支设计和用例登记注明测试入口、原始 shape/axis 与规范化后的 shape/axis；接口支持非尾轴与 Kernel 直接接受非尾轴分别核对。
